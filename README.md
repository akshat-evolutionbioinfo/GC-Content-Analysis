# GC Content Analysis 🧬

A beginner-friendly Python project for analysing DNA sequences and calculating GC content.

## Features

- DNA sequence validation
- Nucleotide composition analysis
- A, T, G and C counting
- GC content calculation
- Basic DNA sequence analysis

## Technologies

- Python
- Basic Bioinformatics

## Example

DNA sequence:

ATGCGTACGTTAGC

The program calculates the nucleotide composition and GC content percentage.

## Learning Goals

This project demonstrates basic Python programming applied to biological sequence analysis.
